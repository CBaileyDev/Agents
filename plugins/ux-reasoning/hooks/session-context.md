The ux-reasoning plugin is installed. Before writing or changing UI code (components, pages, forms, dialogs, toolbars, tables, styles, animations), load the matching skills with the Skill tool, then write the code:
- fetches, lists, or submits data → ux-reasoning:ux-states
- buttons, saves, deletes, toggles, any action → ux-reasoning:ux-feedback
- forms and inputs → ux-reasoning:ux-forms
- custom widgets, dialogs, icon buttons, colors → ux-reasoning:ux-accessibility
- animation or transitions → ux-reasoning:ux-motion
- layouts that must work on phones → ux-reasoning:ux-responsive
- new screens or vague UI requests → ux-reasoning:ux-intent and ux-reasoning:ux-hierarchy
- look and feel, themes, restyling → ux-reasoning:ux-visual-direction
- reviewing or auditing UI → ux-reasoning:ux-heuristics
Skip them for work that does not touch UI.
